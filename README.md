# تواصل: المستوى الأول

- `index.html`: اللعبة، ست عشرة مدينة في جزأين، وسبع مراجعات آخرها «حكايتي». في كل مدينة تسع محطات: المحادثة كاملة، ثم «ابنِ برجًا»، ثم السرد، ثم الكتابة. تكتمل حروف الهجاء كلها في المدينة ١٦.
- `dalil.html`: دليل المعلمة، مع محاكاة درس كامل.

- `lamiya/`: فيلم لامية ابن الوردي، مشهد متحرك لكل بيت مع المعنى والمفردات وسؤال للحوار. يُضاف إليه كلما درسنا دفعة جديدة.
