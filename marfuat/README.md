# محاضرة المرفوعات

سلسلة «أساسيات في قواعد اللغة العربية» — المحاضرة الثانية.

- العرض: `index.html`
- صفحة الطالب: `index.html#student`
- لوحة المحاضر: `index.html#teacher`

## ربط إجابات الهواتف بجدول Google (مرة واحدة)

1. أنشئ جدول Google جديدًا.
2. من القائمة: **الإضافات ← Apps Script**، واحذف ما في المحرّر، والصق محتوى `apps-script.gs`، ثم احفظ.
3. **نشر ← نشر جديد ← تطبيق ويب**: «التنفيذ باسم: أنا»، «من يمكنه الوصول: أيّ شخص». وافق على الصلاحيات.
4. انسخ رابط التطبيق (ينتهي بـ `/exec`).
5. افتح لوحة المحاضر، والصق الرابط في «ربط الإجابات بجدول Google»، واضغط «حفظ واختبار».

بعدها يتضمّن رمز QR الرابط تلقائيًّا، وتصل إجابات الطلاب إلى الجدول وإلى اللوحة كل بضع ثوانٍ.

> ملاحظة: من يملك رابط `/exec` يستطيع قراءة الأسماء والإجابات. لا تنشره خارج القاعة، وأنشئ نشرًا جديدًا لكل دفعة إن أردت.
